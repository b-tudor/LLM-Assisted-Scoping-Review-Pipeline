These files must exist in the working directory:
```
title-abstract-list-CLEAN.csv           (this was auto-generated by the batch job creator from the title/abstract screening stage)
gpt5-title-abstract-screen-results.csv  (or whatever you named your CSV output from the title/abstract screening stage)
full-texts/ID.txt                       (this is a directory full of text documents, named by study id, one for each paper selected for inclusion in the title/abstract screening phase)
```

`title-abstract-list-CLEAN.csv`  
This is A csv file with the columns 'title', 'abstract', and 'id', where 'id' is the unique study id for this paper. This should have been
generated by `create-title-abstract-batch.py` in the title/abstract screening stage. If you don't have it, your original list of paper titles
and abstracts (and study IDs) should work. The CLEAN version just removed or escaped many problematic characters (newlines, quotes, etc).  
  
  
`gpt5-title-abstract-screen-results.csv`  
(Or whatever you named the CSV output from the title/abstract screening stage--this filename is hard-coded so to change it you will need to update the python script). This is csv file made from the LLM output of the previous step. This CSV has the columns 'id', 'include', 'confidence', and 'reasoning'. 'id' is the unique study id for this study. 'include' is either a 'Y' or an 'N' and is the LLM's determination whether the study was to be included or not, based on the title and abstract alone.  
  
`full-texts/ID.txt`   
There must be a text file in this folder for each study marked as a 'Y' in the title/abstract screening results. Here ID (as in ID.txt) is the unique study id for this paper. eg. The text of study 42 should be named `42.txt`.  
  
Run the python script `create-fulltext-screen-batch.py` and redirect its output to the batch file for upload to the OpenAI API.

Eg:  
  
`./create-fulltext-screen-batch.py > batch-full-text-screen.jsonl`  

Then upload the batch job to the OpenAI API using the `upload-batch-job-file.py` utility located in the `tools/` directory. If this script is in your local directory, run:
  
`./upload-batch-job-file.py batchJob-sample_full-text-screen.jsonl`  
  
Like in the first stage, make a note of the file ID for the batch file. Start the batch using the `do-batch.py` tool:  
  
`./do-batch.py <fileID>`  
  
And make a note of the batch ID.
